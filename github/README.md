# Пищевое поведение на инкретинах

Демонстрационное Streamlit-приложение для оценки поступления макро- и микронутриентов по **пяти типовым паттернам питания** пациентов на инкретинах (ГПП-1). Сравнение с нормами по MP 2.3.1.0253-21 и опционально с добавлением **1 саше OPTIFAST**.

## Возможности

- выбор пола (женщина / мужчина);
- выбор одного из 5 пищевых паттернов;
- суточный рацион по приёмам пищи;
- характерные особенности выбранного паттерна;
- панель макро- и микронутриентов с цветовыми индикаторами (≥90% / 60–89% / &lt;60%);
- режим **«Диета + 1 саше OPTIFAST»** — пересчёт фактического поступления и процентов без изменения исходных данных.

## Структура репозитория

```
├── app.py                 # основное приложение
├── requirements.txt
├── README.md
├── data/
│   ├── menus.json         # 5 сценариев рационов и дефициты
│   └── Optifast.Json      # нутриенты 1 порции OPTIFAST
└── streamlit/
    └── config.toml        # оранжевая тема
```

## Локальный запуск

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # macOS / Linux

pip install -r requirements.txt
streamlit run app.py
```

Приложение откроется в браузере (обычно http://localhost:8501).

## Деплой на Streamlit Community Cloud

1. Создайте репозиторий на GitHub и загрузите содержимое этой папки.
2. На [share.streamlit.io](https://share.streamlit.io) укажите репозиторий.
3. **Main file path:** `app.py`
4. Секреты не требуются.

## Данные

- **`data/menus.json`** — демонстрационные усреднённые значения, не для клинической диагностики.
- **`data/Optifast.Json`** — состав одной порции OPTIFAST для режима сравнения.

Редактирование рационов: правьте `menus.json` напрямую; отдельные пересчитанные копии не создаются.

## Требования

- Python 3.10+
- Streamlit ≥ 1.44

## Лицензия и назначение

MVP для обучения и демонстрации. Не заменяет расчёт по ингредиентам и официальные медицинские рекомендации.
